## 🧠 Core Engine Performance Metrics

* **Zero-Bloat Modular Splitting:** Eliminates long HTML string chunking. Separates presentation structural assets cleanly across dedicated file layers (`index.html`, `styles.css`, `app.js`).
* **Precision Center-Snapping Scroll:** Resolves standard browser jump artifacts. When a matching record is targeted, the focus scanner tracks the bounding layout distance coordinates relative to the scrolling inner viewport box container, cleanly centering the targeted element on the monitor.
* **Instant Keyboard Shortcuts:** Pressing the global **`[/]`** key instantly overrides browser defaults and pulls focus straight into the filter box, clearing out previous indices to start a fresh search session.
* **Macro Tag Layout Interpreters:** Natively catches, parses, and styles specialized layout modifiers embedded within text notes—such as copyable code block containers, inline code nodes, and bold highlight tags.
